# Comment on produit nos vidéos d'apprentissage

Alors ce doc, c'est la vue d'ensemble : comment une vidéo naît chez Tolbi, de l'idée jusqu'à sa place dans l'app. Le détail — les checklists, les specs — vit dans le protocole de production, et le fond de la réflexion dans le doc de stratégie.

Le découpage, c'est les cinq phases de n'importe quelle production audiovisuelle : développement, pré-prod, tournage, post-prod, livraison. Un prestataire vidéo s'y retrouve direct.

## 1. Est-ce que la vidéo doit exister ?

En fait tout part d'un ressenti : quelqu'un se dit « il faudrait une vidéo pour ça ». Très bien — mais on ne sort pas la caméra tout de suite. On vérifie d'abord que le besoin tient la route : est-ce que la tâche se montre mieux qu'elle ne s'explique ? Est-ce que l'écran est stable, ou il va encore bouger dans deux sprints ? Est-ce qu'un tuto existant ne couvre pas déjà le sujet ? Les critères complets sont dans le protocole de production, à la gate zéro.

Ça passe ? Feu vert. Ça ne passe pas ? Souvent la bonne réponse est ailleurs : on améliore l'écran lui-même, on ajoute un chapitre à une vidéo existante, ou on glisse une simple instruction dans le formulaire.

## 2. La pré-prod : tout se décide avant de filmer

C'est le moment le moins cher pour changer d'avis. Du coup, avant d'allumer quoi que ce soit :

**On écrit le script et le storyboard.** Pas de tournage sans script — sinon on improvise, et ça s'entend.

**On tranche le genre de chaque séquence.** Deux genres : montrer l'app (screencast du téléphone) ou montrer le geste métier (tournage terrain). La plupart des vidéos mélangent les deux, c'est le storyboard qui dit qui fait quoi.

**On choisit qui apparaît à l'écran.** Pour le terrain, il faut quelqu'un à qui les agents peuvent s'identifier : un agent, un producteur du coin. Pas un présentateur.

**On liste les langues.** Règle simple : une langue = une vidéo. Pas de sous-titres — c'est la voix qui porte la langue, pas le texte.

## 3. Le tournage

On exécute le storyboard, rien de plus. Screen-record pour les séquences app, tournage pour le terrain. Un truc coince ? On ne bricole pas sur place, on retourne corriger le storyboard.

## 4. Le montage

Ça se passe sur Descript. C'est aussi là qu'on décline les versions linguistiques : même image, une piste audio par langue.

## 5. Le contrôle qualité, et en ligne

Dernière étape avant l'app. Trois choses à vérifier :

- la vidéo est **courte** — une vidéo = une tâche, pas plus ;
- elle est **chapitrée** — un agent doit pouvoir revenir sur l'étape GPS sans se retaper les quatre minutes ;
- elle est **légère** — 480p, parce qu'il faut qu'elle se télécharge et qu'elle tienne sur les téléphones du terrain.

Ça passe ? Elle entre au catalogue. Ça ne passe pas ? Retour au montage. Il n'y a pas de troisième cas.
