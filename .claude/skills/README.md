# Skills — Index

Claude Code requiert que les skills soient directement sous ce dossier (pas de sous-dossiers). Cet index documente leur catégorie.

## Product — cadrage & discovery

| Skill | Usage |
|---|---|
| `grill-with-docs` | Challenger un plan contre le modèle de domaine existant (CONTEXT.md, ADRs) |
| `grill-me` | Interviewer l'utilisateur pour valider un plan ou design |
| `to-prd` | Transformer une intention en PRD structuré |
| `to-issues` | Décomposer un PRD en issues actionnables |
| `triage` | Prioriser et qualifier les demandes entrantes |
| `setup-matt-pocock-skills` | Configurer l'issue tracker et le domaine de projet |

## Engineering — build & debug

| Skill | Usage |
|---|---|
| `tdd` | Cycle red-green-refactor, développement piloté par les tests |
| `diagnose` | Boucle de diagnostic pour bugs et régressions de performance |
| `prototype` | Prototype jetable pour valider une logique ou explorer des UI |
| `improve-codebase-architecture` | Opportunités d'approfondissement architectural |
| `zoom-out` | Revue architecturale de haut niveau |

## Workflow — méta & coordination

| Skill | Usage |
|---|---|
| `handoff` | Compacter la conversation en document de passation pour un autre agent |
| `write-a-skill` | Créer un nouveau skill avec structure et ressources |
| `caveman` | Mode communication ultra-compressé (−75% tokens) |
